# Scripture Writing Planner

This repository will contain the source assets and exported PDFs for the "Scripture Writing Planner" — an aesthetically elegant, GoodNotes-optimized digital planner for women using a warm peach/blush/gold/cream/muted-rose palette.

Contents added in branch `scripture-planner-assets`:

- assets/color-palette.svg — color swatches and hex codes
- assets/cover.svg — vector cover design (encouraging, peaceful, polished)
- assets/page-template-daily.svg — daily/planner page template with fillable areas
- assets/page-template-weekly.svg — weekly overview template
- docs/ASSEMBLY_INSTRUCTIONS.md — how to convert the SVGs to a hyperlinked PDF optimized for GoodNotes
